# Zastrzeżenie

**To repozytorium nie zawiera żadnych kluczy DRM, certyfikatów urządzeń ani plików CDM
(`.wvd`) i takie pliki nie będą do niego przyjmowane.**

Projekt odtwarza protokół sieciowy, którym aplikacja Pilot WP komunikuje się z serwerem,
aby na użytek osobisty umożliwić współpracę z oprogramowaniem, z którego użytkownik już
korzysta (np. tvheadend). Dzięki temu strumienie, do których abonent ma prawo w ramach
opłaconego abonamentu, można odbierać w innych programach. Projekt ma charakter edukacyjny
i służy zapewnieniu interoperacyjności.

Opcjonalna obsługa Widevine nie zawiera żadnych kluczy Widevine ani CDM. Aby z niej
skorzystać, użytkownik musi dostarczyć własny, legalnie uzyskany plik urządzenia L3
i ponosi za to pełną odpowiedzialność.

Projekt jest udostępniany w obecnej postaci („as is”), bez jakichkolwiek gwarancji. Nie jest
powiązany z WP / pilot.wp.pl ani przez nie wspierany. Wszelkie prawa do treści należą do
ich właścicieli. Właściciele praw mogą zażądać usunięcia materiałów, zgłaszając to przez
system zgłoszeń (issues) tego repozytorium.

# Disclaimer

**No DRM keys, device certificates, or CDM (`.wvd`) files are included in this
repository, and none will be accepted into it.**

This project re-implements the client-side network protocol of Pilot WP for personal
interoperability with software the user already runs (e.g. tvheadend), so streams a
paying subscriber is already entitled to can be consumed by other clients. It is
intended for educational and interoperability purposes.

The optional Widevine path contains no Widevine keys and no CDM. To use it, a user must
supply their own, legally provisioned L3 device file; doing so is the user's
responsibility.
